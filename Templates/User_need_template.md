# User need title

Follow `docs/Needs_semantic_contract.md`, `docs/User_needs_writing_rules.md`, `docs/Needs_hierarchy.md` and `docs/Lifecycle_states.md`.

This template is not a compulsory form to complete. Keep useful candidates with explicit assumptions; leave unknown material unknown and omit unused optional sections. Select actual metadata values rather than leaving option lists in a real object. Do not claim direct evidence fit when the basis is none.

## Working formulation

Persist the current canonical interpretation in `need`. Describe the progress, protection, recovery or change required without assuming that the user must perform all enabling work. Keep any mirrored body statement consistent with the field.

The familiar `I need to [progress] so that [value]` form is optional. Do not force context, pain, value or an emotional/relational need into one sentence. Context belongs in the wording when it is necessary to distinguish meaning; otherwise retain it below.

## Short name

Use `short_name` as a compact, stable need label for maps, workshops and navigation. Prefer `Need to [verb] [object]` when that preserves meaning. Do not turn the full canonical formulation into the map label, or use a mere topic or feature name.

## Wording rationale

Explain meaning-sensitive choices and what alternatives would change. Distinguish refinement from a different need. Preserve actor, agency, beneficiary and responsibility questions rather than quietly assigning work to the user.

## Interpretation

Why this appears to be a need, which actor experiences it, who benefits and who may be responsible for enabling fulfilment. Do not present an institutional mechanism as the need itself.

## Contextual manifestations (optional)

Situations in which the same need appears; associated source scope, pain, value, urgency and fulfilment limits. Note where context changes the underlying meaning enough to warrant a separate related variant. Do not claim universality from reusable wording.

## Tensions and open questions (optional)
